# Contributing

Default branch is `dev`. Open pull requests against `dev`.

- Use clear, conventional commit subjects (`feat:`, `fix:`, `docs:`, ...).
- Keep the README product-facing: no private ops, host paths, or internal process notes.
- Sign commits when you can so GitHub can show Verified.
- Source files carry a BUSL-1.1 SPDX header. Run `make check-license-headers` before pushing; `make apply-license-headers` fixes missing headers.
